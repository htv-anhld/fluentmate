# Screenshots — Hướng dẫn chụp

Play Store yêu cầu ≥2 screenshot phone (max 8). Khuyến nghị 5–6 ảnh, tỷ lệ 9:16.

## Cách chụp trên iOS Simulator
1. App đang chạy trên iPhone 16e (kích thước 1170×2532, tỷ lệ 9:19.5 — Play Store chấp nhận)
2. Mở màn cần chụp → `Cmd+S` để save vào Desktop
3. Move file vào folder này, đặt tên theo thứ tự `01-today.png`, `02-talk.png`...

## Danh sách màn nên chụp (thứ tự gợi ý cho Play Store carousel)

| # | Màn | Mục đích |
|---|-----|---------|
| 01 | Today hub | Hero shot — thấy streak, daily plan |
| 02 | Conversation đang chat | Show value chính của app: AI coach + bubble chat |
| 03 | Conversation report | Show điểm fluency, mistakes, advice tiếng Việt |
| 04 | Learn (scenarios grid) | Show đa dạng kịch bản |
| 05 | Drill 60s flashcard | Show feature ôn từ vựng |
| 06 | Profile / Progress | Show streak + thống kê |

## Cách chụp trên Android emulator (nếu cần thêm)
- Bật emulator → mở app → nút Camera trong toolbar bên phải
- File lưu vào `~/Desktop/Screenshot_*.png`

## Tỷ lệ
Play Store accept:
- 9:16 / 9:19.5 (phone portrait) ✅ (iPhone simulator default)
- 16:9 (landscape — không cần)
- Min 320px, max 3840px cạnh dài

iPhone 16e screenshot 1170×2532 sẽ vừa.
